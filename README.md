# toy-project

OCR, Flask, Docker, OpenCV, Ollama, Next.js 등 다양한 기술 스택 학습 실습 프로젝트입니다.

## 프로젝트 구조

| 폴더 | 주제 | 기술 스택 |
|------|------|-----------|
| `1103` | OCR 엔진 비교 분석 | Python, Tesseract, EasyOCR |
| `1106` | OCR 웹 애플리케이션 | Flask, Tesseract, PIL |
| `1107` | 로그인/회원가입 + OCR 서비스 | Flask, MySQL, BCrypt |
| `1107Advanced` | OCR 메뉴판 번역기 웹앱 | Ruby on Rails, Tesseract, DeepL API |
| `1110` | 이미지 처리 실습 | OpenCV, NumPy (HSV 색상 분할, 마스킹) |
| `1121` | Ollama 프롬프트 UI | Docker, Ollama |
| `1123` | Nginx 로드밸런싱 | Docker Compose, Nginx (웹서버 3대 구성) |
| `news-ollama-project` | 뉴스 요약 서비스 | Flask, Ollama, NewsAPI, Docker |
| `nextjs-fullstack-app` | 로그인 서비스 + 클라우드 배포 | Next.js, Docker, Nginx, 카카오클라우드 |
